# django-altcha-widget

A Django form field and widget for [ALTCHA](https://altcha.org), the
privacy-friendly proof-of-work CAPTCHA.

By default it runs in a **fully self-hosted mode**: the challenge is generated by
your own server and inlined into the rendered form, so no request ever reaches an
external service.
